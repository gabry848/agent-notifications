# Registro degli esperimenti — suite prefissata

- Design iniziale: pipeline Node a tre ruoli, stesso lavoro N/PA/W; aggiornamenti Coordinator, policy utile durante il lavoro, digest utile solo alla fine, rumore irrilevante.
- Stato: preparazione offline. Nessuna inferenza Pi o esecuzione misurata avviata.
- Gate richiesto: GO del coordinatore con modello/provider default registrati, tariffa applicabile, trasporto congelato e calendario senza contesa con altri workload Pi.
- Eventuali tentativi e modifiche future saranno aggiunti senza rimuovere fallimenti.
- Validazione offline: implementazione di riferimento 19/19 test; fixture TODO 0/19; oracle completo positivo dopo policy e ricevuta; rimozione di un'esportazione condivisa rilevata come errore.
- Emendamento prima di ogni inferenza: cap suite 6 USD equivalenti API, su decisione del coordinatore, per riserve conservative di tre richieste concorrenti con output default. Totale campagna 10 USD invariato. Nessuna modifica a workload/oracle o al limite output del provider. Riferimento: `runtime-budget-amendment.json`.
- Runner verificato senza GO: avvio respinto prima di creare un gruppo o lanciare Pi; `offline-gate-check.json`. Prompt, strumenti reali, telemetria e report sono pronti per il congelamento del runtime dopo preflight.
- Audit pre-GO: corretto un leakage del valore della futura policy nella forma richiesta per il report finale. Il prompt ora richiede il valore osservato senza rivelarlo. Nove combinazioni ruolo/modalità controllate: literal assente. Nessuna inferenza precedente; workload/oracle invariati. Runtime freeze v2, v1 conservata. Import e avvio del server usano `adapter/frozen/`.
- Freeze runtime v3 prima delle misure: loader effettivo del provider Codex nel bundle CLI Pi registrato per path/hash; esposizioni distinte dalle sole reiniezioni. Conservati manifest e snapshot originali v1/v2. L'audit controllerà tutti i diciotto export pubblici e il rendering lungo con la policy ricevuta; l'oracle base esercita un sottoinsieme delle esportazioni in integrazione.
- PA misurato: tre Pi completati, task corretto, 82 HTTP settled/0 unknown, 0,5027344 USD equivalenti API. Gruppo reale circa 209 s, nessuna durata artificiale. Audit indipendente positivo; receiver chiusi, auth link temporanei rimossi.
- N misurato: file e oracle finale corretti, ma view interrotto prima di una richiesta finale dal cap delle **riserve conservative concorrenti**. 54 HTTP settled/0 unknown, 1,1725596 USD equivalenti API. La spesa stimata cumulativa della suite era 1,675294 USD, non 6 USD; il cap6 include le riserve massime delle chiamate ancora pendenti. Esito episodio incompleto, nessuna vittoria temporale dichiarata. N include await finali su ingest/delivery, da classificare dall'audit.
- Dopo la guardia N: W sospeso secondo istruzione del coordinatore; nessun rilancio, variante o nuova inferenza. Cleanup dei processi/receiver e dei soli link auth temporanei registrato senza cancellare il tentativo.
- Consolidazione offline dopo audit definitivo: PA/N usage interamente riconciliato; diciotto export, rendering192/dinamico207, test aggiunti, scope e cleanup verificati. N resta incompleto per view, W non avviato. Report/findings aggiornati con verifiche concluse e latenze dall’ack del produttore; nessuna modifica a sorgenti congelati, tracce o metriche. Il coordinatore conferma nessuna variazione di cap o nuova inferenza; AOVerview in attesa per guardia di capacità.
